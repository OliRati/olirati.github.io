LibreForum

LibreForum is a project aimed at building a community forum dedicated to free software and free software appliances. It provides a space where users can help one another, share their knowledge, and improve their understanding of free software.

  • Docker - Containerization
  • Git - Version control
  • REST API made with Symfony

Retrosystem

RetroSystem is an interactive web interface inspired by classic operating systems. This project showcases DOM manipulation using vanilla JavaScript, without relying on any frameworks. It delivers an immersive user experience throught dynamic windows, visual effects, and modular code architecture. using HTML CSS and JavaScript technologies.

  • HTML5 - Page structure
  • CSS3 - Styling and visual effects
  • Vanilla JavaScript - Core functionality
  • DOM API - Dynamic document manipulation
  • Javascript Events - User interaction handling
  • CSS Transitions - Smooth animations and visual effects
  • Modular JavaScript - Modular code organization
